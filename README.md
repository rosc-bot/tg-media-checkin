# 🎬 自动化签到与观影保活管理面板 (Auto Checkin & Media Keepalive Panel)

一套功能强大、开箱即用的 Telegram 机器人自动化签到与 Emby 观影保活 Web 管理系统。支持多账号调度、按键交互、验证码解析、纯中文状态通知与全量加密备份。

---

## ✨ 核心特性

- 📱 **Telegram 机器人自动化签到**：
  - 支持多 TG 账号统一接入与会话隔离；
  - 支持 Inline Keyboard 按钮自动回调点击与文本命令匹配；
  - 支持 Cloudflare 验证与多种验证码解析处理；
  - 智能超时与断线重试机制，全自动无感巡检。
- 🎬 **Emby 多站点观影保活**：
  - 自动化播放保活任务，自定义观看时长与心跳间隔；
  - 智能轮询防止服主清退休眠账号。
- 🔔 **纯中文精细化通知推送**：
  - 执行结果与错误原因全部本地化为自然中文；
  - 签到积分变动、保活进度一目了然。
- 📦 **全量加密备份与恢复**：
  - 支持一键导出全系统 AES 加密备份文件；
  - 支持合并恢复与全新覆盖导入，多机无缝迁移。
- 🐳 **Docker Compose 一键部署**：
  - 容器化打包，依赖全内置，即启即用。
